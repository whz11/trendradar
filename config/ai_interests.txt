1. AI / Agent 实际应用与落地案例

最高优先级。

关注已经进入真实业务、真实组织或真实工作流程的 AI / Agent 应用。

重点关注：

政务、
公安、
网络安全、
办公、
数据分析、
知识管理、
客服、
法务、
运维、
企业管理

等领域。

优先保留：

- 已经上线或真实试点
- 有明确业务问题
- 有明确 AI 工作流程
- AI 替代或辅助具体人工工作
- 有效率、准确率、成本或人力方面的效果
- 可以迁移到其他业务

相比“用了什么模型”，更关注：

“解决了什么问题、怎么做、效果怎么样。”

4. 企业智能体与业务流程自动化

关注 Agent 如何真正进入业务流程。

例如：

用户提出目标
→ Agent 拆解任务
→ 查询数据库
→ 查询知识库
→ 调用工具 / API
→ 操作业务系统
→ 分析结果
→ 生成材料

重点关注：

Enterprise Agent、
Workflow Automation、
AI Employee、
Digital Worker、
Copilot、
多步骤自动化。

完整业务流程优先于单纯聊天问答。

这是重要技术方向。

即使不是已经落地的应用案例，

只要技术会明显提高 AI / Agent 的实际能力，
也应给予较高评分。

重点关注：

- Context Engineering / 上下文工程

- Long Context / 长上下文
- Context Compression / 上下文压缩
- Context Compaction
- Context Rot
- Agent Memory

- Short-term Memory
- Context Isolation
- Context Sharing

- MCP
- A2A
- Tool Use
- Function Calling
- Skills
- Agent Planning
- Task Decomposition

# ===============================================================
# 核心价值判断
# ===============================================================

对每条资讯优先判断：

1. 是否解决了真实问题？
2. 是否属于新的 AI / Agent 应用？
3. 是否已经上线、试点或生产？
4. 是否有实际效果？
5. 是否能够复制到其他业务？
6. 是否能启发新的 Agent 场景？
7. 是否涉及会显著提高 Agent 能力的新技术？
8. 是否值得进一步研究或做原型？


# ===============================================================
# 技术文章判断
# ===============================================================

不要简单认为：

“技术文章 = 低价值”。

如果技术会明显影响：

Agent能力、
业务落地、
生产稳定性、
开发效率、
成本、
上下文管理、
Memory、
RAG、
工具调用、
Computer Use、
MCP、
多Agent协同

则应保留。

例如：

“新的Agent上下文管理方法”
“长任务Context Compaction”
“Agent Memory工程实践”
“MCP工具权限管理”
“Context Engineering最佳实践”

都属于高价值内容。


纯模型训练算法、
纯数学方法、
小幅Benchmark提升，

如果没有明显应用意义，则降低评分。


# ===============================================================
# 应用案例优先级
# ===============================================================

最高价值：

真实场景
+
明确问题
+
明确AI方案
+
真实部署
+
实际成效
+
可复制性


Agent创意即使暂未大规模生产，

只要场景合理、有明显启发价值，

也可以获得较高评分。


# ===============================================================
# 内容质量过滤
# ===============================================================

降低或跳过：

- 标题党
- 震惊体
- 营销软文
- 广告
- 培训课程
- AI概念炒作
- 无实际内容的融资稿
- 普通厂商PR
- SEO内容农场
- 无可信来源的爆料
- 重复转载

“震惊”
“炸裂”
“杀疯了”
“王炸”
“彻底颠覆”
“逆天”
“史诗级”

等标题默认降低评分，

除非事件本身确实重要。

# 最终目标
# ===============================================================

每天重点回答：

- 今天国家和社会有哪些重要事情？
- 今天别人又把AI用到了什么新的地方？
- 有没有值得借鉴的Agent创意？
- 哪些AI应用已经真正落地？
- 哪些新技术会明显提升Agent的实际能力？
- 哪些案例能够迁移到自己的业务？
- 哪些内容值得深入阅读？
- 哪些方向值得做一个内部PoC？

目标不是了解所有AI新闻，

而是从大量信息中找到真正有：

应用价值、
工作价值、
借鉴价值、
技术价值、
政策价值

的信息。
