1. AI / Agent 实际应用与落地案例

最高优先级。

关注已经进入真实业务的 AI / Agent 应用，包括政务、公安、网络安全、
办公、数据分析、客服、法务、运维、知识管理等场景。

优先保留：
- 已正式上线或真实试点
- 有明确业务流程
- AI 替代或辅助了具体人工工作
- 有效率、准确率、成本、人力等实际成效
- 可以迁移到其他单位或业务场景

相比“用了什么新模型”，更关注“解决了什么问题、效果怎么样”。


2. Agent 创意与新应用场景

重点关注有启发性、可复制的 Agent 创意。

例如：
- 网络黑话、暗语、涉诈话术识别
- 案件材料分析
- 舆情研判
- 安全告警研判
- 日志分析
- 威胁情报分析
- 漏洞研判
- 政策解读
- 公文审核
- 工单处理
- 数据分析
- 报表生成
- 合同审核
- 调研 Agent
- Browser / Computer Use 自动化

即使技术并不复杂，只要场景有价值，也应提高评分。


3. 政务 / 公安 / 网络安全中的 AI 应用

重点关注 AI 在政府、公安、网络治理、网络安全中的真实应用。

关注：
- 政务大模型
- 公安 / 警务大模型
- 网络安全大模型
- SOC Agent
- AI 辅助办案
- AI 辅助情报分析
- AI 辅助网络治理
- 安全运营智能体
- 舆情研判智能体

优先关注真实业务流程、落地方式、人机协同机制和实际效果。
单纯“建设某某大模型”的宣传稿降低评分。


4. 企业智能体与业务流程自动化

关注 AI Agent 如何真正进入业务流程。

包括：
- Enterprise Agent
- Workflow Automation
- AI Employee
- Digital Worker
- Copilot
- 多步骤任务自动执行
- API / 数据库 / 知识库 / 浏览器 / 内部系统调用

尤其关注：
用户提出目标 → Agent 拆解任务 → 调用工具 → 分析结果 →
生成材料 → 人工确认或自动完成闭环。

完整流程型应用优先于单次问答。

6. RAG / 知识库 / 数据分析应用

- RAG / Agentic RAG / Graph RAG

10. AI / Agent 安全

安全作为重要但非最高优先级方向。

重点关注与真实 AI 应用直接相关的风险：

- Prompt Injection
- Agent 越权
- Tool Injection
- MCP Security
- RAG / Knowledge Poisoning
- Memory Poisoning
- Sensitive Data Leakage
- Agent Permission
- Sandbox
- Agent Identity / Authorization

更关注：
这些风险是否会影响实际部署，以及如何通过权限、隔离、审核、
日志、Guardrail 等方式解决。

纯理论安全论文降低评分。

# ===============================================================
# 核心判断标准
# ===============================================================

对每条资讯优先判断：

1. 这是一个真实 AI 应用吗？
2. 解决了什么业务问题？
3. 是否用了 Agent / RAG / 工具调用 / 工作流等能力？
4. 是否已经实际部署或试点？
5. 是否有明确成效？
6. 是否具有可复制性？
7. 是否能启发新的 Agent 应用场景？
8. 是否可以用于政务、网安、公安、办公等业务？
9. 是否包含工作流、架构或工程经验？
10. 是否只是营销宣传？

能明显回答前 8 个问题中的多个，应提高评分。


# ===============================================================
# 高价值案例标准
# ===============================================================

最高优先级案例：

真实业务场景
+
明确问题
+
明确 AI 方案
+
真实部署
+
实际成效
+
可复制性

例如：

“某单位使用大模型自动识别网络黑话和涉诈暗语，
辅助分析聊天记录和网络内容，
将原本人工数小时的研判压缩到分钟级。”

此类案例应给予高评分。


# ===============================================================
# 内容质量过滤
# ===============================================================

降低或跳过：

- 标题党
- 震惊体
- AI 概念炒作
- 营销软文
- 广告
- 培训课程
- 无实际案例的“全面拥抱 AI”
- 无技术或业务细节的融资稿
- 普通公司 PR
- 重复转载
- 无可信来源的爆料
- 低质量内容农场

以下表达默认降低评分：

“震惊”
“炸裂”
“杀疯了”
“王炸”
“彻底颠覆”
“逆天”
“刚刚”
“史诗级”
“遥遥领先”

如果事件本身确实重要，不要因为标题风格直接过滤。


# ===============================================================
# 重复内容处理
# ===============================================================

同一事件多个来源时，优先：

1. 官方原文
2. 使用单位 / 项目方原文
3. 有真实业务流程和效果的数据文章
4. 有系统架构或技术实现的文章
5. 有独立分析价值的文章

普通媒体重复转载降低评分。


# ===============================================================
# 最终目标
# ===============================================================

每天重点回答：

- 今天别人又把 AI 用到了什么新地方？
- 有没有值得借鉴的 Agent 创意？
- 哪些应用已经真正落地并产生效果？
- 哪些案例可以迁移到自己的业务？
- 哪些新模型或新能力会带来新的应用方式？
- 哪些政务、网安、安全场景正在被 AI 改造？
- 哪些内容值得后续深入研究或做内部原型？

如果一篇资讯不能提供明显的：

应用价值、
落地价值、
业务价值、
借鉴价值、
趋势价值

则降低推荐优先级。
